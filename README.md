# Mohammed Umar — Pixel Desert Portfolio

A single continuous portfolio website built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in VS Code with Live Server, or serve the folder with any static web server.

## Deploy to Vercel

Push this folder to GitHub and import the repository into Vercel as a static site. No build command is required.

## Assets

Place/keep the pixel-art assets inside `assets/` using the filenames already referenced by `index.html`.

The global desert background is:

`assets/desertbg.png`

The dinosaur is:

`assets/dino.gif`

## Contact placeholders

Replace these values in `index.html` with your real details:

- `YOUR_EMAIL`
- `YOUR_GITHUB_URL`
- `YOUR_LINKEDIN_URL`

The website is intentionally one long page. The JavaScript uses a centralized state sequence to make the interactive skill, technology, and project transitions predictable while keeping all sections connected.
